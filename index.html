CSCI 286 – Stock Trading Backtester (Java)

A full Java-based backtesting sandbox that processes historical daily OHLC data and simulates a 20-day breakout strategy. Built with modular OOP design using classes: Bar, Trade, and SymbolTester.

Features

  • Parses daily OHLC CSV rows into encapsulated Bar objects
  • Identifies long/short signals using 20-day highs/lows with multi-step confirmation
  • Gap-aware stop-loss and profit-target logic
  • Tracks complete trade lifecycle: entry/exit dates, prices, direction, and holding period
